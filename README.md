# [TCL] Live Transfer

1. `npm install`, fill `.env` (see `.env.example`)
2. Developer Portal: enable **Server Members Intent**
3. Bot role must be above team / manager / assistant roles
4. `npm start` (commands and the logo avatar are set automatically)

Admins: /add_team /appoint /transfer_manager /disband /disband_undo
Manager: /assistant_appoint
Staff: /offer /release /transfer
Players: /demand
Everyone: /roster

All logs go to the #contracts channel.
